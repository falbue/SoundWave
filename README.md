# SoundWave

Плеер SoundCloud на Python, GTK 4 и libadwaita. Режим «Станция SoundCloud» запускает станцию на основе случайного лайкнутого трека; режим «Похожие по лайкам» собирает похожие на лайки треки.

## Запуск

Нужны Docker Compose и сеанс GNOME на Wayland (Debian 13).
При первом запуске создай каталог для сессии:

```sh
mkdir -p ~/.local/share/sound-wave
docker compose up --build
```

Если UID или GID пользователя отличается от 1000, задай `LOCAL_UID` и
`LOCAL_GID` в `.env`.

Docker устанавливает Python-зависимости из `requirements.txt`. GTK, libadwaita,
PyGObject и GStreamer устанавливаются из пакетов Debian.

Чтобы включить диагностику, замени `DEBUG=False` на `DEBUG=True` в
`.env` рядом с `compose.yaml` и выполни `docker compose up -d`.
Сообщения появятся поверх обложки, а журнал сохранится на компьютере в
`logs/debug.log` внутри папки проекта. При `DEBUG=False` приложение
не создаёт папку и не пишет в журнал. В журнал попадают этапы запросов,
коды ответа и ошибки плеера. Токены и адреса аудиопотоков в него не записываются.

## Вход

Чтобы использовать отдельную OAuth-сессию, задай `SOUNDCLOUD_CLIENT_ID` и
`SOUNDCLOUD_CLIENT_SECRET` зарегистрированного приложения в локальном `.env`.
На экране входа вставь refresh-токен, выданный этому приложению через OAuth
Authorization Code. SoundCloud заменяет refresh-токен
при каждом обмене. «SoundWave» сохраняет новую пару токенов в
`~/.local/share/sound-wave/oauth-session.json` и обновляет её по мере истечения
срока. Refresh-токен браузера не подходит для отдельной сессии.
[Документация SoundCloud об обновлении токена](https://developers.soundcloud.com/docs/api/guide#refreshing-tokens)

Без ключей приложения продолжает работать ранее сохранённая веб-сессия.
Для повторного входа вставь `oauth_token` из браузера на экране входа.
В Chrome он находится в **Application → Storage → Cookies → https://soundcloud.com**.

Приложение хранит токены с доступом только владельцу. Веб-сессия находится
в `~/.local/share/sound-wave/session.json`. Для выхода из аккаунта выбери
«Выйти из SoundCloud» в меню слева.

Выбери волну в меню слева. Клик по обложке запускает или приостанавливает
воспроизведение. Во время прослушивания управление появляется при наведении на окно.
Размер квадратного окна можно изменить в меню слева.
Кнопка со ссылкой слева открывает текущий трек в браузере,
где можно поставить лайк. Расширения GNOME и мультимедийные клавиши могут
управлять SoundWave через MPRIS. Для подбора нужен хотя бы один лайк в SoundCloud.
Приложение использует внутренние интерфейсы SoundCloud, которые могут
измениться. Доступность треков зависит от SoundCloud и аккаунта.

При входе через веб-сессию «SoundWave» отправляет запись в историю SoundCloud
после секунды воспроизведения или по завершении короткого трека.
В публичном OAuth API доступно только чтение истории.
