# SoundWave

Минималистичный плеер SoundCloud на Python, GTK 4 и libadwaita

## Принцип работы

Реализовано 2 станции:
- Станция SoundCloud -  запускает станцию на основе случайного лайкнутого трека
- Похожие по лайкам собирает похожие на лайки треки


## Вход в аккаунт

При первом запуске, приложение потребует `oauth_token`. Его нужно взять из **заголовков запроса (!)**, и вставить в приложение

## Известные проблемы

Я знаю, что иногда при входе и прослушивании треков, `API SoundCloud` выдаёт ошибку `403`. Я пока не выяснил с чем это связано
Если эта ошибка появилась при входе, достаточно просто перезапустить приложение

## Локальный запуск
Для локального запуска, тестирования и разработки, создан `compose.yaml`
В корне проекта выполните `docker compose up --build`. Готово
